Revisão de Texto com IA

Configurações · Uso de tokens

Como seus dados são tratados. O texto só sai do navegador quando você aciona a revisão (botão flutuante, atalho Alt+Shift+R ou menu de contexto). No motor "assinatura" ele passa pelo Claude Code local e segue para a Anthropic; no motor "API" vai direto para api.anthropic.com. Nenhum texto é gravado: só ficam salvos a contagem de tokens e o tamanho do texto.

Motor de revisão

A ponte roda claude -p na sua máquina e usa o login do Claude Code (a cota da sua assinatura). Instale uma vez: bash native-host/install.sh (dentro da pasta da extensão) e recarregue a extensão.

Chave de API

Só é usada no motor "API". Fica só neste computador (chrome.storage.local, não sincroniza). Crie uma chave dedicada no console da Anthropic com limite de gasto: chamadas diretas do navegador exigem esse cuidado.

Modelo

Lista de exceções

Palavras e expressões que a revisão deve ignorar (uma por linha). Não diferencia maiúsculas de minúsculas, mas diferencia acentos (ideia ≠ idéia). Vale no prompt e também num filtro em código.

Instruções de estilo

Regras suas que se somam ao prompt base (o formato JSON de saída não pode ser alterado). Exemplo: “Mantenha o trema e o acento diferencial de pôr.”
